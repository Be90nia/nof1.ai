# 峰值回落Level1策略优化说明

## 优化概述

本次优化针对峰值回落Level1策略的反复平仓问题，通过集成蔡森趋势决策，实现智能化的平仓判断。

## 核心逻辑

### Level1触发后的三种处理方式

当峰值回落达到Level1阈值时，系统会调用蔡森趋势决策模块进行分析，根据市场趋势做出以下三种决策：

#### 1. 蔡森指标显示会涨（BULLISH）
- **判断条件**：综合评分 ≥ 70 且多时间框架趋势向上
- **处理方式**：**不执行平仓**，继续持有仓位
- **日志记录**：记录"蔡森看涨，忽略Level1平仓信号"
- **目的**：在上涨趋势中避免过早平仓，获取更多利润

#### 2. 蔡森指标显示会大跌（BEARISH）
- **判断条件**：综合评分 ≤ 30 且多时间框架趋势向下
- **处理方式**：**强制全部平仓（100%）**，覆盖AI填的百分比
- **日志记录**：记录"蔡森看跌，Level1强制全平"
- **目的**：在下跌趋势中及时止损，避免更大亏损

#### 3. 蔡森指标显示震荡（NEUTRAL）
- **判断条件**：综合评分在30-70之间，或趋势不明确
- **处理方式**：**按AI填的百分比平仓**，执行原有逻辑
- **日志记录**：记录"蔡森震荡，按AI百分比平仓"
- **目的**：在震荡市中保持灵活性，按原计划执行

## 蔡森趋势决策指标体系

### 1. 多时间框架趋势分析（权重40%）
- **15分钟趋势**：权重20%，快速反应短期变化
- **1小时趋势**：权重30%，捕捉中期趋势
- **4小时趋势**：权重50%，确认主要趋势方向
- **评分范围**：-100（强烈看跌）到 100（强烈看涨）

### 2. 七分位位置分析（权重30%）
- 基于7天历史数据计算价格分位
- 1/7区域（极低位）：+100分，强烈看涨
- 4/7区域（中位）：0分，中性
- 7/7区域（极高位）：-100分，强烈看跌

### 3. 成交量确认（权重20%）
- 对比最近3根K线与前7根K线的平均成交量
- 成交量大幅放大（>150%）：90分
- 成交量放大（>120%）：70分
- 成交量萎缩（<80%）：30分

### 4. 波动率分析（权重10%）
- 计算最近K线的价格波动率
- 高波动率（>1%）：90分
- 中等波动率（>0.5%）：70分
- 低波动率：30分

在Level1触发逻辑中集成蔡森决策：
- 仅在Level1触发时调用蔡森决策
- 根据决策结果执行三种处理路径

#### 2. `src/caisen/systems/monitor/recordClosingDecision.ts`
增强平仓决策记录：
- 添加蔡森趋势决策字段

## 使用示例

### Level1触发场景

```typescript
// 场景1：峰值回落达到Level1阈值
// 当前盈利：5%，峰值盈利：10%，回落：5%

// 蔡森决策分析
const decision = await getCaiSenTrendDecision("BTC", "long");

if (decision.trend === TrendDirection.BULLISH && decision.score > 70) {
  // 情况1：看涨，不平仓
  logger.info("蔡森看涨(75分)，忽略Level1平仓");
  // 继续持有，等待更高利润
}
else if (decision.trend === TrendDirection.BEARISH && decision.score < 30) {
  // 情况2：看跌，全平仓
  logger.warn("蔡森看跌(25分)，Level1强制全平");
  closePercent = 1.0; // 100%全平
}
else {
  // 情况3：震荡，按AI百分比
  logger.info("蔡森震荡(50分)，按AI百分比30%平仓");
  closePercent = 0.3; // 按AI填的30%
}
```

## 预期效果

### 量化指标
- **Level1触发后的处理分布**：
  - 看涨不平仓：30-40%
  - 看跌全平仓：20-30%
  - 震荡按比例平仓：30-50%
- **平仓频率**：同一币种1分钟内仅执行1次
- **交易次数**：整体减少40-60%
- **净利润**：提升15-25%
- **手续费成本**：降低40-60%

### 非量化效果
- ✅ 消除短时间内反复平仓问题
- ✅ 上涨行情中持有仓位，获取更多盈利
- ✅ 下跌行情中及时全平仓，减少亏损
- ✅ 震荡行情中灵活应对，按AI百分比平仓
- ✅ Level2/Level3保持原有逻辑不变

## 注意事项

1. **仅Level1使用**：蔡森决策仅在Level1触发时调用，Level2/Level3保持原有逻辑
2. **决策失败处理**：如果蔡森决策失败，回退到原有的指标验证逻辑
3. **1分钟保护**：严格遵守1分钟内不重复平仓的保护机制
4. **评分阈值**：BULLISH需要>70分，BEARISH需要<30分，确保决策可靠性
5. **性能要求**：决策计算时间<500ms，不影响10秒监控频率
